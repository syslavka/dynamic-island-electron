# Архитектура Electron 1.1.2

## Окно и ввод

`electron/main.cjs` создаёт прозрачное окно без рамки поверх обычных приложений, управляет треем, монитором, горячими клавишами и автозапуском. Окно острова и окно настроек исключены из панели задач. Системные Acrylic/Mica к острову не применяются.

`electron/geometry.cjs` рассчитывает скруглённые области основного и дополнительного островов. Пустое пространство окна пропускает мышь. Размеры областей обновляются во время анимации, а не только после её завершения.

## Интерфейс

`src/App.tsx` выбирает настольный остров или окно настроек. React-компоненты находятся в `src/components/`, интеграционные хуки — в `src/hooks/`. `src/services/activityPolicy.ts` определяет приоритеты активностей. `src/hooks/useActivityTransition.ts` обрабатывает отменяемые переходы между ними. Темы и пользовательские параметры находятся в `src/context/`.

В `src/services/mockServices.ts` и части компонентов сохранён веб-прототип. Его демонстрационные звонки и погода не являются системными возможностями настольного приложения. Тестовые метаданные используются в smoke-проверке; обычная музыка приходит из Windows.

## Мост к Windows

`electron/preload.cjs` предоставляет небольшой набор типизированных методов. Renderer работает без Node.js, с sandbox и context isolation. Production-страница загружается из локальной сборки с CSP, запрещающей сетевые подключения.

- `media.cjs` / `media.ps1` — Windows Global System Media Transport Controls и команды воспроизведения.
- `Artwork.cs` — получение и преобразование обложки. DLL собирается из исходника системным C#-компилятором; готовая DLL не хранится в Git.
- `activity.cjs` / `activity.ps1` — питание, Bluetooth, ConsentStore, активное приложение и звук.
- `recording.cjs` — запись выбранного пользователем источника в WebM без звука.
- `transfers.cjs` — копирование во временный файл, прогресс, отмена и завершение с заменой результата.

## Сборка и проверка

`npm ci` использует зафиксированный `package-lock.json`. `npm run build` собирает C#-помощник, проверяет TypeScript и выполняет Vite production build. `npm run dist` создаёт переносимый Windows x64 `.exe` через electron-builder.

`npm test` проверяет настройки, уведомления, приоритеты, геометрию и реальные операции копирования/отмены. `npm run test:desktop` запускает настоящее окно с отдельным профилем, проверяет альфа-канал, анимации, таймер и запись собственного окна. Проверки не подменяют аппаратные испытания отсутствующих Bluetooth-устройств или активных медиаплееров.

На GitHub Actions выполняются тесты и Windows-сборка. Тег, совпадающий с `package.json`, например `v1.1.2`, создаёт релиз с `.exe` и SHA-256. В первоначальный релиз загружается сохранённая сборка 1.1.2; её контрольная сумма указана в описании релиза.
