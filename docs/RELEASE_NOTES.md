## Dynamic Island 1.1.2 · Electron

Компактный остров для Windows 10/11 x64: музыка, таймеры и текущие активности поверх рабочего стола.

### Скачать

**`Dynamic-Island-1.1.2.exe`** — переносимое приложение без установки. Для обычного запуска Node.js и сервер разработки не требуются. SHA-256 находится в `SHA256SUMS.txt` рядом с приложением.

### Главное в 1.1.2

- Остров постоянно виден. Когда нет активностей, капсула показывает только время.
- Остров и настройки не отображаются в панели задач; управление доступно через трей.
- Сохранённые настройки старого автоскрытия больше не заставляют остров исчезать.

### Что внутри

Музыка Windows с обложкой и управлением, автоматическое переключение, таймер и секундомер, дополнительный интерактивный остров, системные индикаторы, запись выбранного окна/экрана в WebM, копирование файлов с прогрессом и отменой, темы и автозапуск.

Системный Acrylic отключён, чтобы не создавать серый прямоугольник вокруг прозрачного окна. Стеклянный стиль ограничен поверхностью острова. Оптическое преломление Apple Liquid Glass не заявляется. Набор музыкальных команд, заряд Bluetooth и сведения камеры/микрофона зависят от Windows, драйвера и приложения.

### Быстрый старт

Запустите `.exe`, нажмите на капсулу для раскрытия. `Esc` сворачивает панель, `Ctrl+Alt+S` открывает настройки. Выход находится в меню значка в трее. Перед включением автозапуска переместите файл в постоянную папку.
