# Проверка исправления окна, версия 1.1.1

## Причина и воспроизведение

В 1.1.0 `setBackgroundMaterial('acrylic')` применял DWM-подложку ко всему HWND 600×600. Подложка композировалась вне прозрачной поверхности Chromium, поэтому прозрачный CSS и `setShape` не ограничивали её надёжно. Предыдущие проверки `webContents.capturePage()` видели только Chromium и пропускали системный фон.

На запущенной переносимой 1.1.0 через Windows Computer Use воспроизведён серый прямоугольник. Открытые под ним настройки были визуально закрыты. Отключение стеклянной темы убрало прямоугольник без изменения HTML: это подтвердило источник в DWM material.

## Исправление

- Окно создаётся с `transparent: true`, `backgroundColor: '#00000000'`, `backgroundMaterial: 'none'`, без тени и системного оформления. Во время смены темы DWM materials больше не устанавливаются.
- Стекло, отражения, локальное смягчение и контур ограничены скруглёнными DOM-поверхностями двух островов. Размытие рабочего стола не заявляется.
- Радиус правого острова анимируется между пикселями. Раньше переход `50%` → `29px` возвращал CSS `calc(...)`, который `parseFloat` превращал в NaN и удалял область второго острова во время перехода.
- Переключение модулей использует отменяемое затухание; исходящие элементы управления отключены, новейшая активность заменяет ожидающую. Уменьшение анимации соблюдается.
- Музыка раскрывает плеер даже при уже выбранном компактном музыкальном модуле. После паузы учитывается активность до ручного открытия плеера.

## Выполненная проверка

- 27 модульных/Node-тестов: логика активностей, геометрия, реальное копирование и отмена с сохранением исходных данных.
- Electron smoke: прозрачный alpha-канал вне островов, сохранение двух областей во время morph-перехода, повторный запуск/остановка музыкальной активности, быстрые переключения, сохранение настроек, таймер, настоящая запись собственного окна в WebM.
- Рендеринг 100% и 200% через `--force-device-scale-factor`; текущий системный масштаб — 125%. Проверены окна 480 и 600 DIP и размер интерфейса 80%/115%. Это эмуляция размеров/DPI, а не проверка на всех физических мониторах.
- Запущенная переносимая `.exe`: через Windows Computer Use проверены светлая и тёмная локальные подложки, отсутствие серого прямоугольника, реальный клик в подложку через неиспользуемую область HWND (счётчик изменился с 0 на 1), основная капсула, раскрытый плеер с настоящей обложкой Windows, воспроизведение/пауза и возврат, таймер в круге справа и раскрытие его панели.
- После окончательной пересборки выполнен обычный запуск без диагностического флага с прежними сохранёнными настройками пользователя. Включена исходная стеклянная тема, проверены реальный клик по капсуле, раскрытая панель и сворачивание. Прямоугольного системного фона нет. Изменять аппаратное ускорение или удалять пользовательский профиль не потребовалось.

Для повторения ручной проверки: `Dynamic-Island-1.1.1.exe --visual-check`. Открывается локальная тестовая подложка с кнопкой-счётчиком; используется отдельный временный профиль, без изменения обычных настроек. При обычном запуске это окно не создаётся.
